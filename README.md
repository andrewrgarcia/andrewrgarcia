I build and ship production software — full-stack systems and the infrastructure underneath them — and before that, forecasting for Peru's Central Bank and teaching CS at the university level. The tools below aren't side projects collecting dust; they're things I built because the existing option broke under real use, and then kept maintaining because people other than me started depending on them.

## Philosophy

I build tools that survive contact with reality.

Reality includes developers, researchers, terminals, AI agents, broken workflows, and occasionally me.

Projects usually begin where friction starts:

- **Viceroy** → AI agents hand you abstract instructions instead of applyable code
- **FUR** → conversations become memory sludge
- **Yggdrasil** → codebases stop fitting inside context windows
- **Moxi** → AI can reason about text but still struggles with 3D worlds
- **Elaine** → references should not require ritual suffering
- **Martian** → explainability should not require notebook worship

As for whose reality:

mostly mine.

Possibly people from the year 2808.

## Tools

| | |
|---|---|
| **[Viceroy](https://github.com/andrewrgarcia/viceroy)** | A coding-agent skill that delivers applyable edits — whole file or exact verbatim swap, never "insert this somewhere." Backed by 3 deterministic benchmarks (no LLM judge): on a real, unmodified slice of published scientific C, it hits 90% task-completion with zero collateral damage on a free local model, vs. 0% for the same model with no skill. 58 self-tests, $0 to reproduce. |
| **[FUR](https://furchats.vercel.app)** | Conversation control for LLMs — context management, interaction history, traceability. |
| **[Yggdrasil](https://crates.io/crates/yggdrasil-cli)** | Flattens a codebase into a single injectable markdown artifact. Built for real AI workflows. |
| **[Membrane](https://crates.io/crates/membrane-cli)** | YAML-based knowledge system where each entry carries its own schema. No database required. |
| **[powerxrd](https://github.com/andrewrgarcia/powerxrd)** | Powder XRD analysis in Python — the only known open-source project with a Rietveld refinement method in active development. |
| **[voxelmap](https://github.com/moxilang/voxelmap)** | Turns images and arrays into voxel and 3D mesh models. |
| **[AESus](https://github.com/andrewrgarcia/aesus)** | AES-256-GCM encryption with Argon2id-derived keys and Diceware passphrases. Rust CLI + library. |
| **[Elaine](https://github.com/andrewrgarcia/elaine-cli)** | Deterministic, local-first LaTeX bibliography generator. Built because citation managers kept breaking. |
| **[Martian](https://github.com/andrewrgarcia/martianbook)** | Turns ordinary code into interactive execution reports — no Jupyter notebooks required. |
